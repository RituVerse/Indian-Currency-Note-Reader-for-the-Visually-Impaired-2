### Decisions
- Classes: 10, 20, 50, 100, 200, 500, no_note. **2000-rupee class dropped** (withdrawn May 2023).
- **no_note class is SYNTHETIC** — 35 images generated by `generate_no_note.py` (solid colours, gradients, Gaussian noise, blurred blobs, fine textures). No real hand/table/room photos used. See Limitations.
- **No phone photos used** — user decision. No real-world test set exists.
- Model: MobileNetV2 (ImageNet weights, 224x224). Transfer learning: frozen base (15 epochs), then fine-tune last 20 layers (15 more epochs).
- Split: 70/15/15, random seed 42. Duplicates (MD5) removed before splitting. no_note images added directly to `dataset_split/`.
- Augmentation: rotation (±15°), brightness (±20%), zoom (±10%). **No flips** — they would reverse the note's design.
- Confidence threshold: 85%. Below threshold → "Not sure. Please show the note again."
- Training settings: batch 8, ~20 fine-tune layers, early stopping (patience 8/10).
- **No voice / speech output anywhere** — visual result only.

## Problem Statement
India uses banknotes in denominations of Rs.10, Rs.20, Rs.50, Rs.100, Rs.200, and Rs.500.
Many users — elderly people, people with low vision, tourists, and anyone unfamiliar with
the designs — struggle to tell them apart quickly.

## Proposed Solution
A browser-based web app that uses the device's camera or a photo upload to classify the
denomination in real time using a MobileNetV2 neural network exported to TensorFlow.js.
The answer appears in large, high-contrast text (e.g. **"This is a Rs.500 note"**),
with a confidence bar. No installation required — runs entirely in the browser.

## Target Users
- Elderly people and people with low vision
- Tourists unfamiliar with Indian currency
- Anyone needing quick denomination confirmation

## Dataset
**Kaggle dataset:** "Indian Currency Note Dataset" — *paste author name and licence from the Kaggle page here.*
- Original 7 classes (Train + Test folders pre-split by Kaggle)
- ~22 images per class in Train, ~6 per class in Test
- 15 exact duplicates removed (MD5 hash comparison)
- 2000-rupee class excluded (withdrawn from circulation May 2023)
- **no_note class**: 35 synthetic images (not from Kaggle) — see `generate_no_note.py`

## Training Process
1. All Kaggle images (excluding 2000-rupee) pooled from Train+Test and re-split 70/15/15 (train/val/test), random seed 42, after MD5 deduplication.
2. 35 synthetic no_note images added: 24 train / 5 val / 6 test.
3. Total dataset: 158 train images, 26 val images, 34 test images (7 classes).
4. MobileNetV2 (pretrained on ImageNet) used as the feature extractor. Top replaced by: GlobalAveragePooling → Dense(128, ReLU) → Dropout(0.3) → Dense(7, softmax).
5. **Phase 1 – Frozen training:** base layers frozen, top layers trained for 15 epochs (LR=1e-3).
6. **Phase 2 – Fine-tuning:** last 20 layers of MobileNetV2 unfrozen, 15 more epochs (LR=1e-5).
7. Best model selected by highest validation accuracy (ModelCheckpoint callback).
8. Augmentation: random rotation (±15°), brightness (±20%), zoom (±10%). No flips.

## Test Results on Kaggle Test Set

> **Important:** The test set has only **~3–6 images per class** after deduplication and the 70/15/15 split.
> A single wrong prediction changes a class score by 17–33 percentage points.
> **These results are noisy.** All test images are clean Kaggle studio photos — real webcam accuracy was NOT measured.
> The no_note class is synthetic; real-world performance on empty frames / hands / tables is unknown.

## Limitations
1. **Very small dataset** — ~22 Kaggle images per note class. Test accuracy is noisy.
2. **No real-world photos used** — all training data is clean, consistent studio shots. Real webcam accuracy will be lower in poor lighting, with folded/worn notes, or unusual angles.
3. **Synthetic no_note class** — the model was shown colour blocks and noise instead of real hands, tables, and wallets. It may still name a denomination when no note is present.
4. **No Rs.2000 note** — officially withdrawn May 2023. If a Rs.2000 note is shown, the model will misclassify it as the closest-looking denomination.
5. **Old vs new note designs** — the dataset may not cover all design variants.
6. **Poor lighting** — confidence drops in dark or back-lit conditions; the 85% threshold should catch many of these cases.
